# Analytical Assumptions

Every assumption used in analysis or decision-making across this project

## Data Cleaning
- We assumed that the number of group tickets in row 43 was a manual data input error, so we used the average number of group tickets per game in that season to remove the outlier.


## Portfolio-Level Projections

- Full Season and Group tickets held flat for all 3 projected years. Full Season matches the pricing recommendation while Group is just held there since it was never investigated further.

## Single Game Decline

- We assumed that we would convert Single Game buyers to Partial Season, but without internal data there is no way to confirm.
- In the go-forward analysis, Single Game's continued decline is projected forward at a tapering rate (Year 1 = full 2022-23 rate, Year 2 = 2/3, Year 3 = 1/3). This was a judgment call that a severe rate won't persist unchanged for 3 years.

## Partial Season Package Sizing (3-2-1 & 3-6-9)

- For the 3-6-9 plan, we assumed that customers would select M-T-W games evenly across the 9 games (3/each)
- Assumed Partial Season pricing would increase based on 2021-2023 historical price growth rate.
- To hit the 75% growth goal, we assumed baseline growth stayed constant, 3-2-1 takes over single game losses, and 3-6-9's carried the leftover
- Assumed that we would not hit a capacity limit for any one game. One capacity check run used the single highest Total Tickets value ever recorded (37,365) as a stand-in for stadium capacity, but that was not an issue.

## Concessions Price

- **20 dollars/fan/game assumed spend** This is not Acme's actual data since it was not provided. Grounded on a rough pricing of one hot dog + drink + snack.
- Assumed constant regardless of ticket price, meaning a fan paying less for a ticket is assumed to spend the same $20 on concessions as one paying more.


## Data Limitations

- Since there was no data on team performance, weather, competing events, or promotions, those factors were all ruled out as potential drivers of declines.
